# CMPE 249 HW: Zero-shot 2D detection, COCO → nuImages (Track A)

Evaluates three COCO-pretrained detectors from three families on COCO val2017 and, without retraining, on nuImages v1.0-val:

| Model | Family | Checkpoint |
|---|---|---|
| YOLO11m | one-stage, anchor-free | Ultralytics `yolo11m.pt` |
| RT-DETR-L | query-based transformer, NMS-free | Ultralytics `rtdetr-l.pt` |
| Faster R-CNN R50-FPN v2 | two-stage, anchor-based | torchvision `COCO_V1` |

The report is in [`report/report.pdf`](report/report.pdf).

## Layout

```
src/nuimages_to_coco.py   nuImages val -> COCO-format GT on 6 shared classes (+ ignore regions)
src/run_detector.py       run one detector over a COCO-format image set; save detections + latency/memory
src/evaluate.py           pycocotools COCOeval: summary, per-class AP, per-class AP by size
src/analyze.py            figures + failure analysis (recall by height, confusions, rider/rack checks)
src/build_report.py       report.md -> self-contained report.html (printed to PDF)
run_all.sh                accuracy runs: 3 models x one dataset
run_speed.sh              clean latency/memory benchmark (1000 images/dataset, idle GPU)
results/                  metrics.json / metrics_6cls.json / speed.json per dataset and model
logs/                     console log of every run, environment (env.txt)
report/                   report source, figures, analysis.json, PDF
```

Raw `detections.json` files (40–480 MB each), datasets and weights are not committed. They are regenerated by the commands below.

## Reproduce

Environment (as used): Ubuntu 22.04 (WSL2), RTX 4070 Ti, Python 3.11, torch 2.5.1+cu124, torchvision 0.20.1, ultralytics 8.4.190, pycocotools 2.0.11. See `logs/env.txt`.

```bash
conda create -n det python=3.11 -y && conda activate det
pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu124
pip install ultralytics pycocotools nuscenes-devkit pandas matplotlib markdown

# data: COCO val2017 + annotations -> ~/data/coco ; nuImages v1.0 all-metadata + all-samples -> ~/data/nuimages
python src/nuimages_to_coco.py --out data/nuimages_val_coco6.json
bash run_all.sh coco
bash run_all.sh nuimages
bash run_speed.sh
python src/analyze.py
```

Settings: FP32, batch 1, score threshold 0.001, max 300 detections/image. NMS IoU is 0.7 for YOLO11m and 0.5 for Faster R-CNN (torchvision default); RT-DETR is NMS-free. Inputs are 640 for the Ultralytics models and 800/1333 for Faster R-CNN.
